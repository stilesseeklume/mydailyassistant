# 礼堂排座 · 设计文档

日期：2026-08-29
状态：已获用户确认，进入实现

## 背景与目标

年级主任经常在大礼堂（两层、34 排、1179 座）开年级会议。每次会议班级数量、各班人数都不同；有时第一排整排或部分留给领导；颁奖会议需要台下前排右侧的颁奖学生席位。目标：一个可反复使用的排座工具，挂到 seeklume.work，每次只填班级和人数，自动得到每班的楼层/排/座号段，并输出可打印的平面图、班级指引单、汇总表和 Excel。

## 场地数据（从大礼堂 PDF 矢量精确提取，内嵌进模块）

- 一楼 27 排 933 座：第 1 排 13 座（中区）；2~9 排 30/31/34/35/36/37/36/37 座（左中右三区，扇形展开）；9~10 排之间有横向过道；第 10 排 22 座（仅中区）；11~22 排各 40 座（9+22+9）；23~25 排各 38 座（8+22+8）；26~27 排各 14 座（仅左右区 7+7）。
- 二楼 7 排 246 座：1~4 排各 37 座（8+21+8）；5 排 35；6 排 33；7 排 30（4+21+5），阶梯收窄。
- 每排座位号从左到右 01 起连续编号；数据含每排每段的真实坐标，平面图按真实布局等比绘制（扇形、过道、收窄都会呈现）。

## 输入（工作台左侧）

- 会议名称 + 日期（打印标题/存档用）。
- 班级列表：名称 + 实到人数，可增删、上下移动；抽签按钮随机打乱（可重抽）；一键载入上次班级表。
- 排座设置：
  - 楼层：只用一楼 / 两层都排。
  - 排向：前→后 / 后→前（两层各自按此方向）。
  - 二楼班级数：默认 4，排座顺序末尾 N 个班上二楼；0 = 只用一楼。
  - 整班优先（放不下就整班挪下一排，前排留空）/ 紧凑排座（拆两排续接，不留空）。
  - 领导席：开关 + 数量（默认 13 = 一楼第 1 排整排，从 01 号占起）。
  - 颁奖席：开关 + 数量；位置固定为「台下前排、主席台右侧」——从一楼最前排可用的排开始，每排从最右号往左占；可选粘贴获奖学生名单逐个对号。
  - 粒度：班级级（默认）/ 学生级（每班可粘贴名单，一行一人，取最后一个词为姓名）。

## 排座算法（纯函数，确定性）

1. 预留：先扣领导席（一楼第 1 排从左），再扣颁奖席（一楼从前排右侧往回）。
2. 班级按当前顺序（表格序或抽签序）排队；末尾 N 个班分配到二楼，其余在一楼。
3. 每层内按排向遍历各排的可用座位序（每排从左到右，跳过已预留座位）：
   - 当前排剩余装得下 → 就地连座。
   - 装不下且（整班优先）下一排整排装得下 → 整班挪到下一排，前排留空；紧凑模式则先填满当前排剩余再续下一排。
   - 班级人数超过任何整排 → 跨相邻排续接（如 5 排 01-40 + 6 排 01-10）。
4. 学生级：按名单顺序填入本班座位段。
5. 超容量：红字警告「坐不下，差 N 座」，班级照排，排不下的座位段标灰。

## 输出（工作台右侧，实时随参数重算）

- 状态条：总人数 / 可用座位 / 已排 / 剩余空位；超容警告。
- 平面图（SVG，按真实坐标等比）：舞台在上、两楼分组、排号双侧、座位按班着色 + 图例（班级色块/领导席/颁奖席/空位）；可切换显示座位号、显示姓名（学生级）；点击座位显示详情；打印（A3 横向 @media print，隐藏控件只留图和图例）。
- 汇总表：班级、楼层、排、号段、人数。
- 班级指引单：每班一张卡（楼层 + 排 + 号段 + 入场提示），一键全部打印（每班分页）。
- Excel 导出：Sheet「汇总」+ Sheet「明细」（学生级含逐座姓名）+ Sheet「预留」（领导/颁奖）。
- localStorage 保存最近会话与历史（自动，防抖）；导出/导入 JSON 备份。学生名单只存本机浏览器，不进仓库、不上传。

## 边界与不做

- 不做账号、不做云同步、不做教室（非礼堂）排座。
- 礼堂座位结构为硬编码数据；若场地改造，改 hall-seating.js 顶部的 HALL 数据。
- 隐私：仓库只提交代码与礼堂结构数据；不含任何学生信息。
