# My Daily Assistant

个人日常小工具集合。每个工具独立运行，数据本地处理，不上传服务器。

## 工具列表

| 工具 | 说明 | 路径 |
|------|------|------|
| 🧪 成绩单转换 | 上传 Excel 成绩单 · 自动识别板块 · 120→130 换算 · 合并听说算总分 | `score-analysis/` |
| 🏛 礼堂排座 | 填班级和人数 · 班级聚集第一 · 领导席/颁奖席预留 · 平面图/指引单/Excel | `hall-seating/` |

## 使用方式

直接在浏览器中打开各工具目录下的 `index.html` 即可使用，无需安装、无需登录。

## 特点

- **本地优先**：所有数据处理在浏览器本地完成，关闭页面即清空
- **独立部署**：每个工具自成一体，互不依赖
- **持续添加**：按需加入新的小工具
